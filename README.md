# 在現場的人 · Those present

宏福苑大火採訪專題的獨立文字報導網站。保留原報導、作者署名、可展開註解、三位記者介紹與相關報導連結。

## 開啟網站

直接開啟 `index.html`，或在此資料夾執行：

```sh
python3 -m http.server 4173
```

瀏覽 http://localhost:4173/ 。無須安裝套件或編譯。

## 部署

可將整個資料夾放到靜態網站主機。GitHub Pages 可選擇目前分支的根目錄 `/ (root)`。使用相對路徑，支援專案子目錄。尚未發布至網路。

## 內容來源

來自桌面 `Thosepresent/code/thosepresent/public/article.html` 與三位記者介紹頁；圖片沿用原專案。僅清除原稿中的 `??` 殘字及軟對抗註解中重複的文字與 HTML 殘碼，其他報導文字保留。原始專案未修改。本次為網站整理，未重新查核報導事實或外部連結內容。
